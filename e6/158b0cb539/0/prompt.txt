### Important

**1. A resumed `generate` can put the wrong reference clip next to existing audio** (`tts.py:100-109`, `tts.py:118-131`, `cli.py:148`)
- `generate` skips any `&lt;idx&gt;-&lt;method&gt;.opus` that already exists. But it still writes the new plan's `text` and `ref` into `generation.json`. I reproduced this:
  - A first run with an empty library made `000-matched.opus` from `heath-miller.wav`.
  - A second run after the library existed called the synthesizer 0 times, but recorded `ref = hwfwm-female-0-0.wav` with `fallback: False`.
  - The page then labels audio made from the narration clip as the female clip, with no badge.
- Other ways to hit it:
  - Re-running `chapter` (bonsai at temperature 0.3 gives different passage boundaries), then generating: old audio stays matched to the same passage index under new text.
  - Re-running `match` or `cluster`. `cluster` also rewrites the same clip filenames (`hwfwm-&lt;cid&gt;-&lt;n&gt;.wav`) with different audio, so the page plays a different clip than the one used.
  - Name samples are named by position in the alphabetical names list (`name-{k:02d}-…`). Adding a name, which the per-book list is meant for, shifts the numbering, so an existing file gets shown under a different name.
- For an experiment Noah judges by ear, this mislabels results silently. `test_generate_skips_existing_outputs` locks in the skip but doesn't check the record.
- Fix: store the text and ref file (or a hash of text, ref file and ref contents) next to each output, and regenerate when they differ. Name the samples by the name itself, not its position.

**2. A female line can get a male clip when no female voice has a clean clip, and the page doesn't say so** (`clusters.py:241`)
- `enforce_group` falls back to `... if same else pick`. If the right group has no usable cluster, it keeps bonsai's pick, which can be from the wrong group.
- Probe: `enforce_group([female line], ["male-0"], {"male-0": "male", ...})` returns `["male-0"]`.
- `pick()` then finds clips for `male-0`, so `fallback` stays False. The page shows "Reference clip: &lt;speaker&gt; · gruff man" with no badge.
- This is the exact failure the experiment exists to fix. The ledger notes female dialogue was once "never isolated", so a re-cluster could plausibly leave no usable female cluster. In the current run, female-0 and female-1 have clips.
- Fix: return `None` when `same` is empty, so `pick()` falls back to `heath-miller.wav` and marks it. Add a test.
